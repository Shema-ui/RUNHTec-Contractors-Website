# RUNHTec Contractors Ltd: Website

Company website for **RUNHTec Contractors Ltd**, an engineering and construction company with offices in Rwanda (Kigali) and Uganda (Kampala).

It's a plain HTML/CSS/JavaScript site, hosted free on **GitHub Pages**.

## Files

| File | What it is |
|---|---|
| `index.html` | The whole page: text, sections, contact details |
| `css/style.css` | Colours, fonts and layout |
| `js/main.js` | Mobile menu and the quote form (sends via WhatsApp or email) |
| `images/` | Logo and project photos |

## Editing

- **Change text or phone numbers:** edit `index.html`. Phone numbers also appear in `js/main.js` (`WHATSAPP` and `EMAIL`).
- **Change a photo:** upload a new image into `images/` with the same file name.
- Every change committed to `main` goes live automatically in 1–2 minutes.
